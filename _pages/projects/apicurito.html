Deprecated: Apicurito has been superseded by the Apitomy OpenAPI Editor, which provides a more capable, embeddable visual editing experience. Apicurito is no longer actively maintained.

Features

🌐

Browser-Based

Design and edit OpenAPI specifications directly in your browser with a clean, intuitive visual interface.

⚡

Lightweight

A standalone, focused editor application with minimal dependencies. Get started designing APIs immediately.

📄

OpenAPI Support

Create and edit OpenAPI 2.0 (Swagger) and OpenAPI 3.0 specifications with full visual editing capabilities.

💾

Import / Export

Import existing API specifications and export your designs in JSON or YAML format for use in your projects.
