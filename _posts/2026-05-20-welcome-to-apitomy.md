We're excited to introduce **Apitomy** -- a new open source brand for tools built around API and
Schema specifications.

Apitomy is born from the [Apicurio](https://github.com/Apicurio) community. As Apicurio Registry
moves to the CNCF, the remaining projects are continuing under the Apitomy banner with the same
mission: making it easier to work with OpenAPI and AsyncAPI specifications.

## What's included

Apitomy currently includes the following projects:

- **[Data Models](https://github.com/Apitomy/apitomy-data-models)** -- A Java and TypeScript library
  for reading, writing, and manipulating OpenAPI and AsyncAPI documents.
- **[Codegen](https://github.com/Apitomy/apitomy-codegen)** -- Generate client SDKs, server stubs,
  and more from OpenAPI specifications.
- **[Data Models MCP](https://github.com/Apitomy/apitomy-data-models-mcp)** -- An MCP server that
  enables AI coding assistants to work with OpenAPI and AsyncAPI documents.

## Get involved

All Apitomy projects are open source under the Apache License 2.0. We welcome contributions,
feedback, and ideas. Visit our [GitHub organization](https://github.com/Apitomy) to get started.
