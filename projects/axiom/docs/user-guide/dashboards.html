    Dashboards

    Dashboards give you an at-a-glance view of what Axiom is doing: which workflow runs are running, failing or waiting, which tasks need your input, how events are flowing through subscriptions, what AI usage costs, and whether the application is healthy.

    You can create as many dashboards as you like. Each dashboard has a name, an optional description, optional labels, and one or more tabs. Each tab holds widgets arranged on a 12-column drag-and-drop grid.

    Opening dashboards

    • Dashboards in the sidebar (/dashboards) opens the default dashboard. If no dashboard is the default, it shows the dashboards list instead.
    • The dashboards list is always at /dashboards/all. Every dashboard has an All dashboards button that returns to it.

    The default dashboard

    One dashboard at a time can be the default. Click the star icon in the dashboards list, or Set as Default on a dashboard, to make it the default. The first dashboard you create becomes the default automatically.

    Creating a dashboard

    From the dashboards list:

    • Create Dashboard creates an empty dashboard with one tab. Click Edit, then Add Widget, to fill it.
    • Create from Template creates a dashboard that already contains a set of widgets. Choose a template, change the name if you want, and optionally add labels. The result is an ordinary dashboard: you can edit, rearrange or remove its widgets afterwards.

    When there are no dashboards yet, the empty list offers the templates directly.

    Templates

    Template Widgets
    Operations Runs by Status, Application Health, Tasks Awaiting Input, Recent Failed Runs, Waiting Runs, Upcoming Schedules
    Event Operations Event Source Health, Subscription Processing, Event Volume, Processing Failures, Recent Events
    AI Usage AI Cost Summary, AI Usage Breakdown (by workflow), AI Usage Breakdown (by model), AI Cost by Subject

    Editing a dashboard

    Click Edit to unlock the layout. In edit mode you can:

    • Drag and resize widgets.
    • Click a widget's gear icon to change its settings, or its X icon to remove it.
    • Click Add Widget to open the widget catalog, which groups widgets by category and marks widgets that ignore dashboard labels.
    • Add, rename and remove tabs.
    • Change the dashboard's name, description and labels.

    Click Save to keep your changes. Refresh reloads every widget.

    Label scoping

    Dashboard labels are subject labels. When a dashboard has labels, widgets that show subject-related data only include data for subjects that have all of those labels, for example only the runs, tasks and AI usage of subjects labelled team=a. This uses the same label filter as the Subjects, Inbox, Activity and AI usage pages.

    Some data is not tied to a subject (event sources, subscriptions, schedules, system health), so those widgets are global and always show everything. When a dashboard has labels, each widget shows a Filtered or Global badge next to its title so you can tell which is which.

    For AI usage widgets, usage that is not linked to any subject cannot match the labels, so it is left out. These widgets tell you how much cost was excluded this way.

    Live refresh

    Most widgets update by themselves:

    • Live widgets reload when Axiom sends a matching server event, for example when a workflow run changes status, a human task is added or removed, a new stream event arrives, or event processing changes. Reloads are debounced (about 2 seconds), and during a steady stream of events a widget still reloads at least every 10 seconds. Widgets also reload after the browser reconnects to the server.
    • Polling widgets reload on a timer.
    • The remaining widgets update when you click Refresh or reopen the dashboard.

    Widgets

    In the tables below, Scope is either Filtered (dashboard labels apply) or Global (dashboard labels are ignored). Time windows are 24 hours, 7 days, 30 days or 90 days.

    Recent Activity Latest workflow, task and subject activity, with links to the subject, trace and event. Filtered Live (activity) Max entries (default 15)

    Widget Shows Scope Refresh Settings

    Sharing dashboards

    Dashboards can be included in configuration packs. On the export page, select them in the Dashboards section. On import, dashboards are matched by name like other items: an existing dashboard with the same name is reported as a conflict. An imported dashboard becomes the default only if it was the default when exported and no dashboard is already the default.
